# DriveBoss (MVP)

DriveBoss is an iOS native app (SwiftUI) to manage driving-related earnings, mileage, gas lookup and car health.

Quick Start

```bash
# 1. Clone the repository
git clone <your-repo-url>

# 2. Switch to develop
git checkout -b develop

# 3. Open in Xcode
open DriveBoss.xcodeproj
```

Project structure (source):

- Source/App — App entry point
- Source/DesignSystem — Colors, typography, layout tokens
- Source/Views — SwiftUI views and screens
- Source/ViewModels — MVVM view models
- Source/Models — Codable data models
- Source/Services — Networking & API clients
